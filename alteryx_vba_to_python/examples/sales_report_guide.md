## How to read this

- **Containers** are the boxes Designer draws around groups of tools. They are numbered 1, 2, 3… in the order they run.
- **Branches**: inside a container, the rows flow along branches. A branch is a chain of tools with no split or merge in it; it is named after its first tool's note or its filter test. Branch 3.4 is the 4th branch of container 3.
- **Steps**: each tool is one step, numbered within its container (step 3.14). The `#1373` after it is the tool's ID in Designer.
- **Card fields:**
- **In** — where the rows come from. A filter has outputs True and False; a join has J (matched), L (left rows with no match) and R (right rows with no match).
- **Does** — the step in one sentence.
- **Rule** — the full expression. `when … → …` lines are read top down; the first true condition gives the value.
- **Reads** / **Writes** — the columns the step uses and the columns it creates or changes (with the type Alteryx gives them).
- **Out** — where the rows go next. An output that nothing uses drops its rows.
- **Python** — the same step in pandas. `df` is the table flowing through the branch; other tables are named after the step that made them (`s2_7` is step 2.7's output, `s2_7_true` its True output). Then the conversion status, and the name of the exact function in the generated module.

        """Alteryx "=": text is compared ignoring case; null equals null."""

        return (fold(a) == fold(b)) | (null(a) & null(b))

## Before relying on this

  - **A3** — Input: column types depend on Alteryx's file driver; the types recorded in the workflow are applied when present
  - **A4** — Join: row order of the three outputs and null = null on keys are not documented
  - **A5** — Output: cell formats written by Alteryx are not reproduced; writes only with Context(write=True)
  - **A6** — Sort: position of nulls and the order of upper/lower case are not documented
  - **A7** — Summarize: output order, Sum of no values and Concat of empty values are not documented
  - **A8** — Union: the type chosen when inputs disagree, and the order of the inputs, are not documented
  - **A9** — Unique: output order is assumed to be the input order
