Robot template

        
Copy templates/robot_template.py, rename, fill the three TODOs. It gives you --env --dry-run --business-date, a one-copy lock, a run folder, JSON-lines logs, a checkpoint and exit codes.

        
python my_robot.py --env dev [--dry-run] [--business-date 2026-03-06]

        

      

      

        
Design rules

        
    
          
  • Blanks never match a condition (except is null); unparsable values become NaN / NaT, never a wrong number.
    • 
          
  • Text is compared trimmed and case-insensitive (lookups, rules, reconcile, required columns) unless you ask for case=True.
    • 
          
  • Column names are matched tolerant of case, spaces and punctuation; a miss names the near misses.
    • 
          
  • Errors are classified: BusinessError = data is wrong, record and skip; SystemError_ = environment, retry; other RobotError = stop, needs a fix.
    • 
          
  • Never retry a send; retry reads only. Writes go through a temp file and rename.
    • 
          
  • Logs carry ids, never data; everything logged is redacted.
    •
